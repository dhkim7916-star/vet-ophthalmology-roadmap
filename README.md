# 수의안과 기능적 시각행동 연구 — 시각 강화 로드맵

GitHub Pages 배포용 단일 페이지 사이트입니다.

## 업데이트 방법
1. 기존 GitHub Pages 저장소의 `index.html`을 이 폴더의 `index.html`로 교체합니다.
2. `.nojekyll`은 그대로 저장소 루트에 둡니다.
3. GitHub에 커밋하면 기존 Pages 주소가 같은 링크로 업데이트됩니다.

## 시각·인터랙션
- 시야검사형 안구–기능행동–생활 적응 도식
- 환자군·과제별 백내장 회복곡선 개념도
- 통증·염증·환경·약물 교란요인 네트워크
- 기반연구에서 장기 확장으로 이어지는 연구경로
- 발표 모드, 상세 보기, 테마 전환, 현재 섹션 링크 복사

※ 회복곡선은 가설 설명용 개념도이며 실제 임상데이터나 예측모형이 아닙니다.

# 수의안과 기능적 시각행동 연구 로드맵

교수 면담용 단일 페이지 인터랙티브 HTML입니다.

## 바로 열기

`index.html`을 브라우저에서 열면 됩니다. 외부 라이브러리나 빌드 과정이 필요하지 않습니다.

## 공개 링크로 배포하기

### GitHub Pages

1. 새 **Public** 저장소를 만듭니다.
2. 이 폴더의 `index.html`을 저장소 루트에 업로드합니다.
3. 저장소 `Settings → Pages`에서 `Deploy from a branch`를 선택합니다.
4. `main / (root)`를 선택하고 저장합니다.
5. 표시되는 Pages 주소를 교수님께 공유합니다.

### Netlify Drop

이 폴더 전체를 Netlify Drop 화면에 끌어다 놓으면 정적 링크가 생성됩니다.

## 포함된 상호작용

- 섹션 스크롤 내비게이션과 현재 위치 표시
- 핵심/상세 보기 전환
- 밝은/어두운 테마
- 백내장 환자군·과제별 가설 탭
- 통증·불편 교란요인 탐색
- 단계별 후속 연구 로드맵
- 현재 위치 링크 복사
- 키보드 조작과 reduced-motion 대응
